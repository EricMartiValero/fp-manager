FP Manager

Gestión de centros FP y candidatas a prácticas

1. Crear proyecto Supabase (gratis)

Ve a supabase.com, crea una cuenta gratis y pulsa "New project". Anota la contraseña de la base de datos.

2. Ejecutar el SQL de setup

En tu proyecto Supabase, ve a SQL Editor (icono de base de datos en el menú izquierdo). Abre el archivo setup.sql que viene con esta app y pégalo todo. Pulsa "Run".

Esto creará las tablas y cargará los 11 centros FP.

3. Copiar URL y anon key

Ve a Settings → API en tu proyecto Supabase. Copia la Project URL y la anon/public key.

Tus datos se guardan localmente en este navegador. No se comparten.
